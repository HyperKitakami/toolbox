工具模板

这是一个可运行的最小工具页骨架：左边输入、右边输出，逻辑在 js/tools/_template.js 里。复制整个目录就能开新工具。

模板 本地运行
输入
输入内容不会离开浏览器
输出 

        

      


    


    

      

        
怎么用

        
    
          
  • 复制 tools/_template/ 为 tools/<slug>/
    • 
          
  • 复制 js/tools/_template.js 并改名为 <slug>.js
    • 
          
  • 在页面底部引入你的脚本，并在 registry 里注册
    • 
        

      

      

        
约定

        
    
          
  • 事件一律在 JS 里绑定，不写内联 onclick
    • 
          
  • 面板、统计、输出区复用 css/tool.css 的类名
    • 
          
  • 颜色只用 css/base.css 里的 CSS 变量
    •
