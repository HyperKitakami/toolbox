Markdown 转 HTML

左边写 Markdown，右边直接拿到干净的 HTML。支持 CommonMark 与 GitHub Flavored Markdown，可切换代码 / 预览两种视图，输出前会做一次净化。

已上线 本地运行 GFM
Markdown
输入内容不会离开浏览器

输出
— 

      


    


    

      

        
支持的语法

        
    
          
  • 标题、列表、链接、图片、引用、分隔线。
    • 
          
  • GFM 扩展：表格、任务列表、删除线、围栏代码块。
    • 
          
  • Markdown 里写的原生 HTML 会被保留，但脚本与事件处理器会被剥离。
    • 
        

      

      

        
关于 Tailwind 选项

        

          Markdown 生成的 HTML 是纯语义标签，本身不带样式。勾选「Tailwind 工具类」后，
          会给每个元素补上 text-3xl、mb-4、
          list-disc 这类工具类，方便直接放进 Tailwind 项目。
          这些类只有在你的项目引入了 Tailwind 之后才会生效；预览区始终显示不带类的语义版本。
        

      

      

        
草稿保存

        

          编辑器内容会自动保存在浏览器的 localStorage
          （键名 toolbox-md2html），刷新后仍在。
          这是本工具唯一的本地写入，不包含任何标识信息；点「清空」会同时清掉草稿。
