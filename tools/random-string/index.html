随机字符串

按指定的字符集与长度批量生成随机串，适合做 ID、token、盐值或测试数据。 随机源用的是浏览器的 crypto.getRandomValues —— 和密码学随机数同源，不是 Math.random。

字符集怎么选

  • 十六进制 —— 只有 0-9a-f，放进 URL、文件名、 日志都不会被转义，也适合做数据库主键的字符串形式。
  • Base64 URL 安全 —— 把标准 Base64 里的 + 与 / 换成 - 与 _， 不用再做百分号编码就能直接进 URL。做 token 时常用这一档。
  • 大小写字母 + 数字 —— 通用的一档，肉眼可读、复制不会出错。
  • 全部可见字符 —— 带符号，同样的长度下熵最高，适合做测试数据； 做 token 时注意某些符号在 shell 与配置文件里要转义。
  • 自定义 —— 目标系统有明确约束时用（比如「只允许小写字母与数字」）。 输入里重复的字符会自动去重，实际使用的字符集实时显示在下面。

随机源：为什么不是 Math.random

  • 本工具只使用 crypto.getRandomValues，它由操作系统提供熵源， 与浏览器生成密钥、会话 ID 用的是同一套接口。
  • Math.random 的实现是可预测的伪随机 —— 只要观察若干输出就能 推出后续序列。用它生成的 token 或盐值等于没生成。
  • 如果环境里拿不到 crypto.getRandomValues（极少见）， 本工具会直接报错，不会偷偷退回 Math.random。
  • 取值用的是拒绝采样：把 32 位随机数里超出「字符集大小的整数倍」的那一小段 丢掉重取。常见的 随机数 % 字符集长度 写法会让靠前的字符出现得略多 （模偏差），字符集越小时越明显。

熵值怎么读

  • 熵值 = 长度 × log₂(字符集大小)，代表攻击者平均要试多少次才能猜中， 单位是比特。
  • 勾选「首字符必须是字母」后，第一位只从字母里取，所以是 log₂(字母数) + (长度-1) × log₂(字符集大小)，比不勾时略低一点点。
  • 经验值：64 比特以下基本可以被枚举，只适合做非敏感的标识； 128 比特以上用于 token、盐值、会话 ID 是稳妥的。
  • 熵值只衡量「随机性够不够」，不代表字符串本身安全 —— 它仍然可能被日志、 剪贴板或截图泄露出去。

常见用途

  • 接口调试用的临时 token、API Key 占位符。
  • 数据库里的随机 ID、幂等键、订单号后缀。
  • 密码哈希的盐值（每个用户一个，长度 16 字节以上）。
  • 造测试数据：固定长度的随机字段，用来测边界与索引。
