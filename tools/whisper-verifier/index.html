日语语音校对

把 Whisper 的日语转录结果贴进来，工具会把它（连同可选的音频）交给你配置的大模型， 拿回校对后的完整文本、每个词的候选写法与把握程度，还有一句整句建议。 想只核对某几个词就标出疑难词，不标就通读全文自己找。

会联网 需自备 API Key
这是站内唯一会联网的工具。 点「开始分析」之后，你的音频与文本会发往上面选定的接口（Anthropic / OpenAI / Google，或你自己填的地址）， 由对方处理并按其计价方式收费。API Key 只存在这台设备的浏览器里， 本站没有服务器，也不经手这些数据。

用起来是三步

  • 先在接口配置里填上你自己的 API Key，选服务商与模型名。 配置自动存在本机，下次打开还在。
  • 把 Whisper 的转录结果整段贴进来。音频可给可不给 —— 给了模型能对着听，判断更准；不给就只凭文本与背景说明推断。
  • 点「开始分析」。想让它只核对某几个词，就把那几行疑难词回车加进去； 一个都不加也行，它会通读全文自己找可疑处。

数据会发到哪里

  • 点「开始分析」时，音频（如果给了）与全部文本会发往你选定的那家服务商。 之后怎么处理、留存多久，以对方的隐私政策为准，本站不经手也无法干预。
  • API Key 明文存在这台设备的 localStorage 里， 不会发往任何本站的地址。共用电脑上用完请点「清除 Key」。
  • 费用按对方计价方式产生，与本站无关。返回内容由模型生成，未必准确，重要内容请自己再核一遍。

结果怎么看

  • 最上面是校对后的文本 —— 模型按建议改完的完整文本，可以直接复制去用。
  • 下面每个词一张卡片：左边是原词，右边是模型的推荐写法，中间按可能性排序列出候选。 候选后面的百分比是模型自己的把握，越高越可信；低于 50% 的会标出来， 提醒你别急着采纳。
  • 再下面是判断理由（音似、上下文、语法），最下面是整体建议。
  • 「翻译」把校对后的文本翻成面板上选的语言，点「看原文」可以切回来。 原词与候选始终保持日语原样，不会被翻掉。
  • 模型如果没有按约定的 JSON 格式回答，页面会保留它的原始输出，不会让你两手空空。
