JSON 格式化

粘贴 JSON 即可格式化、压缩或校验。带语法高亮与行号， 解析失败时定位到具体的行列并给出中文说明。

已上线 本地运行 粘贴即格式化
输入 JSON
输入内容不会离开浏览器

输出
— 

      


    


    

      

        
三种操作

        
    
          
  • 格式化：按选定缩进重新排版，并给出行号与语法着色。
    • 
          
  • 压缩：去掉所有空白，产出最小的单行 JSON。
    • 
          
  • 仅校验：只检查语法是否合法，不改动输出区，适合快速确认。
    • 
        

      

      

        
校验规则

        
    
          
  • 遵循 JSON 标准（RFC 8259）：键名必须用双引号，不允许注释与尾随逗号。
    • 
          
  • 解析使用浏览器内置的 JSON.parse，与运行时行为一致。
    • 
          
  • 报错信息会把 position 换算成行列号，并翻译成中文说明。
    • 
          
  • 键名重复时以最后一个为准，与标准一致，不做额外提示。
    •
