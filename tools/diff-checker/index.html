文本差异对比

把两段文本逐行比对，标出新增、删除和修改的行；修改的行还会进一步标出具体改了哪几个字。 支持并排与统一两种视图，可忽略大小写、行首尾空白与空行。

对比规则

  • 以行为单位比对，连续的非相同行会按相似度对齐，相似的配对成「修改」，其余保持独立的删除 / 新增。
  • 配对成功的行会再做一次字符级比对，标出真正改动的位置。
  • 连续 9 行以上的未变更内容会折叠，点击即可展开。
  • 结尾的换行符不参与比对，a\n 与 a 视为相同。

常见用途

  • 对比两版配置文件、SQL 脚本或代码片段。
  • 核对翻译稿、合同条款改了什么。
  • 检查接口返回的 JSON 在两个环境之间有无差异。

关于复制

「复制 unified diff」导出的是 - / + 前缀的纯文本差异， 会包含全部行（不受折叠影响）。开启忽略选项后，行号与原始文件不再一一对应， 因此导出内容不带头部 @@ 行号标记。
