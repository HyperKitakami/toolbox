渐变生成器

可视化调线性、径向、圆锥三种 CSS 渐变：增删色标、拖动位置、改角度，右边实时预览， CSS 代码点一下就复制。懒得调就从 10 套预设里挑一个，或者直接随机。

已上线 本地运行 3 种渐变类型
渐变设置
色标 2–10 个；位置相同时会形成一条硬边，这是 CSS 的正常行为
预览与代码
色标轴上的圆点就是各个色标的位置；点代码框也能复制
预设
点一下套用；预设会替换掉当前的全部色标，角度与类型保持不变

三种渐变类型

  • 线性 —— 沿一条直线过渡，角度 0° 是从下往上、90° 从左往右，顺时针增加。背景和按钮最常用。
  • 径向 —— 从中心向外辐射，适合做聚光、圆形光晕。
  • 圆锥 —— 绕中心旋转过渡，适合做色环、饼图。部分老版本浏览器不支持，用之前查一下目标环境。
  • 打开「重复」会生成 repeating- 版本，色标按同样的方式排列，但整个图案会沿轴重复铺开，适合做条纹背景。

色标与位置

  • 色标数量限制在 2–10 个。少于 2 个构不成渐变，太多则不好调。
  • 位置按百分比算，0% 是渐变轴的起点、100% 是终点。
  • 列表顺序和位置可以不一致 —— CSS 会按位置排序渲染。两个色标位置相同时会形成一条硬边， 这正是做「双色分界」的常用手法。
  • 点「添加色标」会把新色标插在当前空隙最大的区间中点。 上游是「最后一个位置再加上到 100 的一半」，默认的 0% / 100% 两个色标算出来还是 100%， 新色标和末尾完全重合，点了按钮看不出任何变化。

关于随机

随机时会先取一个基准色相，再让各色标沿着色相环铺开（跨度 40°–180°）， 饱和度和明度也都限制在有彩色的区间里。 完全随机取 RGB 经常得到两个几乎一样的灰，渐变看起来就是一片糊。 快捷键是 R，焦点在输入框里时不会触发。
