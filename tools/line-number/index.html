批量加行号

给每一行加上序号，或者统一的行前缀 / 后缀。序号有十进制、十六进制、字母、罗马数字与中文七种写法， 起始值与步长自定，位数不够可以补零对齐；空行是原样保留、也参与编号、还是直接删掉，由你决定。 右侧实时给出结果，并用主题色标出哪部分是工具加上去的。

          处理概览
        

        

          

        

        

          
        

      


    


    

      

        
每行是怎么拼出来的

        
    
          
  • 序号在行首：前缀 + 序号 + 分隔符 + 原文 + 后缀
    • 
          
  • 序号在行尾：前缀 + 原文 + 分隔符 + 序号 + 后缀
    • 
          
  • 关掉「加序号」：前缀 + 原文 + 后缀
    • 
          
  • 分隔符始终夹在序号与正文之间，所以行尾模式下它落在正文的后面。
            要 foo #3 这种效果，把分隔符改成 # 并在前面留一个空格即可。
    • 
          
  • 空行（连只有空格的行也算）默认原样保留、不占编号；
            选「也编号」它会拿到 3.  这样一行；选「删除」则整行去掉。
    • 
          
  • 结尾的那一个换行不算一行：a↵b↵ 编号后仍只有两行，
            即使选了「删除空行」也不会把结尾的换行吃掉。CRLF 与 CR 都会统一成 LF 输出。
    • 
          
  • 右侧预览里用主题色标出的部分就是工具加上去的；标记只包一层
            <span>，一个字符都不增删，所以「复制」与「下载」拿到的是完整的纯文本。
    • 
        

      

      

        
七种序号格式的边界

        
    
          
  • 数字：十进制，起始值可以是负数（-3. foo）。
    • 
          
  • 十六进制：小写、不带 0x，负数带前导 -。
    • 
          
  • a b c / A B C：电子表格列名那样的进位 —— z 之后是
            aa，不是 ba；起始值小于 1 时回落到十进制。
    • 
          
  • 罗马数字：标准只定义了 1–3999（MMMCMXCIX 是上限），
            超出范围的行改回十进制输出。
    • 
          
  • 中文数字：按万 / 亿 / 万亿分节，中间缺位补「零」（一千零一）；
            10 写成「十」而不是「一十」；超过 16 位同样回落到十进制。
    • 
          
  • 补零只对数字与十六进制生效，按总位数补 ——
            -7 补到 3 位是 -07（负号占一位），
            序号本身的位数超过设定值时不会被截断。
    • 
          
  • 任何一行因为超出格式范围而回落成十进制时，底栏会写出有几行 —— 不静默处理。
    • 
        

      

      

        
常见用途

        
    
          
  • 日志或清单加序号：默认设置即可（1.  开头，空行不编号）。
    • 
          
  • 生成 item_001 这类标识：分隔符设「无」、前缀写
            item_、打开「补零对齐」。
    • 
          
  • Markdown 有序列表：分隔符 . ；引用块：前缀
            > 。
    • 
          
  • SQL 的 IN 列表：前缀写 '、后缀写
            ',，配合行尾逗号一起用。
    • 
          
  • 给每行补丁缩进：前缀填四个空格，关掉「加序号」。
    • 
          
  • 行尾编号（正文 #1）：位置改「行尾」、分隔符写
             #。
