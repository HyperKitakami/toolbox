文本大小写转换

一个输入框，十种写法。驼峰、帕斯卡、下划线、短横线、常量命名之间可以互相转换， 也能把整段文本改成全大写、全小写、词首大写或句首大写。 点任意一行就能复制。

词元是怎么切出来的

  • 先按大小写边界切：getHTTPResponse 会切成 get / http / response。 缩写词尾巴也认（HTTPServer → http + server），所以常量名、缩写混排的变量名都能正确还原。
  • 再按非字母数字切：空格、下划线、短横线、点、斜杠、逗号……都是分隔符， 连续出现只算一个。
  • 非拉丁字母会被保留：中文、日文、西里尔字母都算词元的一部分。 它们没有大小写，转出来还是原样，但不会被悄悄删掉。
  • 命名风格会把整段合成一个标识符：多行输入会先合并成一行再转换。 要逐行转换，请用「批量查找替换」那类按行处理的工具。

十种写法

  • 命名风格（hello world example 为例）： helloWorldExample（camelCase）、 HelloWorldExample（PascalCase）、 hello_world_example（snake_case）、 hello-world-example（kebab-case）、 HELLO_WORLD_EXAMPLE（CONSTANT_CASE）。
  • 整段大小写：全部大写、全部小写、词首大写（Title Case）、 句首大写（Sentence case）、交替大小写（aLtErNaTiNg）。
  • 「句首大写」在句末标点后开新句：中文的 。！？… 后面通常不加空格，所以直接生效；英文的 . ! ? 要求后面有空白，hello!world 这种写法不会被拆成两句。

常见用途

  • 把一种语言的命名习惯搬到另一种：get_user_name → getUserName（Java / JS）、 get-user-name（CSS 类名、URL slug）。
  • 常量名规范化：maxRetryCount → MAX_RETRY_COUNT。
  • 标题、按钮文案的英文大小写统一。

来源与致谢

  • 移植自 jamalofski/praticulus 的 text-case，作者 Jamal Tantaoui / Iris Digital，MIT 许可。
  • 移植时做了三件事：界面全量中文化、改用本站的设计系统与组件类名、 逐段审逻辑并修复缺陷。改动清单见 THIRD-PARTY.md 与 js/tools/text-case.js 的文件头注释。
  • 修掉的主要缺陷：驼峰边界不认缩写词尾 （getHTTPResponse 会变成 get_httpresponse）、 非拉丁字母被静默丢弃（café → caf， 中文输入转出来是空串）、don't 被当成两个词 （Title Case 给出 Don'T）、 中文句末标点不认、空输入时给出十行空白结果。
