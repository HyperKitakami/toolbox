KCWiki 语音台词

按 wiki 的场合表逐条填日文与中文，一键生成可以直接粘贴进条目的 Wikitext。 内置 28 个常规场合与 24 个整点时报，可以追加自定义场合、把不存在的场合整条标成省略， 再按完成度筛出还没填的。填写的内容只保存在这台设备上。

已上线 本地运行 草稿自动保存
生成设置

档名由「角色 ID - 档名后缀」拼成，例如 560-Intro。 角色 ID 没填会按 ??? 显示，也不能生成。

将清空全部台词文本与省略标记，自定义场合也会一并删除，角色 ID 保留。此操作无法撤销。
— 草稿自动保存在这台设备的浏览器里，不会上传
台词条目
当前筛选下没有条目 换一个筛选条件，或者把「隐藏已省略的场合」关掉。

内置的 52 个场合

        
    
          
  • 常规台词 28 条：入手 / 秘书舰 / 建造完成 / 出征 / 战斗 / 中破 / 击沉 /
            结婚 / 图鉴介绍 … 档名后缀与 wiki 模板里用的写法一致（Intro、
            Sec1、DockLightDmg …）。
    • 
          
  • 时报 24 条：0000–2300，
            按整点排，场合名用汉字数字（0100 → 〇一〇〇时报）。
    • 
          
  • 自定义场合追加在列表末尾，可以自己指定分组；把分组名留空就用场合名当分组名。
    • 
          
  • 每个分组都能单独收起 —— 点分组标题那一整行（标题、条数或行末空白）即可，
            三个分组互不影响。「展开全部」会把所有分组与条目一起展开；
            「折叠全部」只收条目、保留分组标题，方便先扫一遍目录。
    • 
          
  • 条目收起后只留一行；行末的「整条省略」开关不会跟着收起，
            所以可以先扫一遍目录、把不存在的场合顺手勾掉，再回头逐条填台词。
    • 
        

      

      

        
状态怎么判定

        
    
          
  • 日文与中文都填了 → 已完成；
            只填了一边 → 部分缺失；
            两边都空 → 未填写。
    • 
          
  • 勾上条目行末的「整条省略」（即该场合不存在）后单独归为已省略：
            它不参与生成，也可以从列表里整个隐藏掉。
    • 
          
  • 两侧都填完才建议生成 —— 只有一边时模板里的另一栏会是空的。
    • 
        

      

      

        
生成的 Wikitext

        
    
          
  • 每个场合生成一个 {{台词翻译表}} 块，
            整篇前后套 {{台词翻译表/页头}} 与 {{页尾}}；
            被标成省略的场合直接跳过。
    • 
          
  • 台词里不要出现 |。
            在 MediaWiki 里 | 是参数分隔符，| 会把一条台词
            切成两个参数、后面的内容全错位。需要时写成 {{!}}。
            工具在生成时会检查并提醒，但不会替你改文本。
    • 
          
  • 生成的顺序就是列表顺序：常规台词在前、时报在后、自定义场合在最后。
