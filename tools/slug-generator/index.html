转换规则

        
    
          
  • 先切词再拼接：字母与数字连成一段算一个词，其余字符（空格、标点、符号）都当分隔符。
            连续分隔符只算一个，首尾的分隔符会被去掉。
    • 
          
  • 中文转拼音：全拼模式下每个汉字是一个词
            （你好世界 → ni-hao-shi-jie）；
            首字母模式下连续的中文合并成一个词
            （你好世界 → nhsj）。
    • 
          
  • 重音符号自动去除：Café →
            cafe、München →
            munchen，用的是 Unicode 分解 + 去组合标记。
    • 
          
  • 拼音不带声调：带调符号（nǐ）在 URL 里会被
            百分号编码成一串 %C7%90，所以这里统一用无声调形式。
            lü 按 slug 惯例写成 lv
            （「绿色」→ lv-se），避免与「路」的 lu 混淆。
    • 
        

      


      

        
拼音表与多音字

        
    
          
  • 拼音表来自 Unicode Unihan 数据库的 kMandarin 字段，
            收录 GB2312 范围内的 6763 个汉字（403 个音节），覆盖日常使用的绝大部分汉字。
    • 
          
  • 多音字取 Unihan 给出的第一个读音：长 会转成
            zhang，如果你要的是 chang，
            直接把输入里的那个字改成拼音写出来即可。
    • 
          
  • 不在表里的汉字按分隔符处理，底部会提示有几个字没查到拼音。
            〇 是个特例：Unicode 把它放在「CJK 符号和标点」区块里，
            Unihan 也没给它拼音，所以它同样不在表内；扩展 B 区之后的字（如
            𠮷）也一样。
    • 
        

      


      

        
常见用途

        
    
          
  • 给中文文章标题生成 URL：如何用 Python 写爬虫 →
            ru-he-yong-python-xie-pa-chong。
    • 
          
  • 批量处理一列标题，一次拿到整份 slug 列表（一行一个）。
    • 
          
  • 给图片、视频文件重命名，避免中文文件名在跨平台传输时乱码。
    • 
          
  • 限制长度的场景（如数据库字段 50 字符）可以在词边界处自动截断。
