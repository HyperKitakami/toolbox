关于引擎

  • 使用浏览器内置的 JavaScript 正则引擎（ECMAScript 语法），不是 PCRE 或 Python 的 re。
  • 因此 (?<name>…)、后行断言、Unicode 属性转义等较新特性都可用，但 PCRE 的 (?P<name>…) 之类不适用。
  • 所有匹配都在本地执行，表达式与文本不会上传。

匹配规则

  • 不加 g 标志时只返回第一个匹配。
  • 加上 g 或 y 后会遍历全部匹配，最多保留 5000 条。
  • 像 a* 这类可能产生空匹配的表达式，会在空匹配处自动前进一位，避免陷入死循环。
