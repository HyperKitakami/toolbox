渲染规则

  • 使用 CommonMark + GitHub Flavored Markdown：表格、任务列表、删除线、围栏代码块。
  • 单个换行会渲染成换行（与写作时所见一致），段落之间仍需空行。
  • Markdown 里写的原生 HTML 会保留，但脚本与事件处理器会被剥离。

草稿与隐私

  • 编辑器内容自动保存在浏览器的 localStorage（键名 toolbox-md-preview），刷新后仍在。
  • 这是本工具唯一的本地写入，不含任何标识信息；点「清空」会同时清掉草稿。
  • 渲染全程在本地完成，文档内容不会上传。

与「Markdown 转 HTML」的区别

本工具面向阅读：实时渲染、大纲跳转、字数统计。 如果你要的是产出 HTML 代码（含语法高亮、Tailwind 工具类输出）， 请用 Markdown 转 HTML。
