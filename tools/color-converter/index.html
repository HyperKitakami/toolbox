颜色格式转换

输入任意格式的颜色值，一次拿到 HEX、RGB、HSL、CMYK、HWB 五种写法。 可以带上透明度，还会告诉你它最接近哪个 CSS 命名颜色。

已上线 本地运行 支持透明度
输入颜色
100%
支持 HEX、rgb()、hsl()、hwb()、颜色名与 8 位 HEX
转换结果
点击任意一行即可复制该格式的色值

五种格式怎么选

  • HEX：#RRGGBB，最通用的网页写法，紧凑。
  • RGB：红绿蓝三个 0–255 的分量，直观，适合屏幕配色。
  • HSL：色相 / 饱和度 / 亮度，调明暗和鲜艳度时最好用。
  • CMYK：青品黄黑，用于印刷。这里的换算是近似值， 没有 ICC 配置文件时 RGB 与 CMYK 之间不存在唯一解。
  • HWB：色相 / 白度 / 黑度，比 HSL 更贴近人挑颜色的直觉。

关于透明度

  • 勾选「含透明度」后，输出会变成 8 位 HEX（#6c5ce7ff） 与 rgba() / hsla()。
  • 滑杆只在勾选后才可用；滑到 100% 时按完全不透明处理，输出退回 6 位 HEX。
  • CMYK 与 HWB 不含透明度信息，始终按不透明计算。

关于命名颜色

「最接近的 CSS 命名颜色」是按 RGB 空间的欧氏距离找出来的，只是一个近似建议 —— 距离为 0 才是精确匹配。这里的 148 个颜色名与浏览器自己的颜色库一致， 测试里会逐个交叉验证。
