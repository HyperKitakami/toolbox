空白清理

把从网页、PDF、聊天记录里复制来的文本规整一遍：删掉行尾空白、合并连续空格、压掉多余空行， 并清除零宽字符、全角空格、方向控制符这些肉眼看不见的东西。每项都可以单独开关， 右侧实时给出结果，下方列出文本里到底藏了什么。

检测报告
—

检出的五类不可见字符

  • 特殊空格：全角空格（U+3000）、不换行空格（U+00A0）、窄空格（U+2009） 等 16 种「长得像空格但不是空格」的字符，统一换成普通空格。
  • 零宽字符：零宽空格（U+200B）、零宽连字（U+200D）、字节顺序标记（U+FEFF）、 软连字符（U+00AD）等，占位置但不显示，直接删除。
  • 方向控制符：LRM / RLM 与嵌入、覆盖、隔离符（U+202A–U+202E、U+2066–U+2069）， 常被用来在代码里藏字符，直接删除。
  • 换行类字符：垂直制表符（U+000B）、换页符（U+000C）、下一行符（U+0085）、 行分隔符（U+2028）、段分隔符（U+2029），只受「统一为 LF」控制。
  • 控制字符：除制表符与换行符以外的 C0 / C1 控制符，直接删除。

处理顺序

  • 换行统一 → 不可见字符 → 制表符转空格 → 逐行空白 → 空行 → 首尾空行。
  • 顺序固定且会影响结果：先合并连续空格再删行尾，行尾剩下的单个空格才会被删掉。
  • 同时开「制表符转空格」与「连续空格」时，制表符会先变成 N 个空格、再被合并成一个； 想保留制表符的对齐效果，就不要同时开这两项。
  • 「显示不可见字符」下，空格显示为 ·、制表符为 →、行尾为 ¶， 残留的不可见字符标成 ⟦U+200B⟧ 这样的码位。

常见用途

  • 从 PDF、网页、聊天记录复制来的文本，往往混着不换行空格与多余空行。
  • 提交代码或 Markdown 之前，清掉行尾空白与文件末尾的空行。
  • 排查「两段代码看起来一模一样却不相等」——多半是零宽字符在作怪。
