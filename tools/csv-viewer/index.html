CSV 查看器

把 CSV / TSV 渲染成表格，自动探测分隔符与文件编码。支持表头识别、 点击表头排序、分页浏览，并可导出 JSON 或 TSV。

支持的格式

  • 按 RFC 4180 的常见子集解析：引号包裹的字段、"" 转义的双引号、字段内的换行与分隔符。
  • 兼容 \n 与 \r\n 两种换行，结尾的空行会被忽略。
  • 文件开头的 UTF-8 BOM 会被自动去掉 —— Excel 导出的 CSV 常带这个不可见字符，不去掉会让第一列列名多一个隐形字符。

探测规则

  • 分隔符：在第一个非空行里比较逗号、分号、制表符、竖线的出现次数，取最多的那个。引号内的分隔符不计入，所以单列 CSV 的值里含分号时不会被误判成多列。
  • 编码：默认先按 UTF-8 严格解码，失败则回退 GBK。中文用户的 Excel 导出多为 GBK，这一条能省掉手动切换。
  • 自动探测不准时，可以在上面手动指定分隔符与编码。

大文件与分页

  • 表格一次只渲染一页（默认 500 行），避免几十万行直接把页面卡死。
  • 排序作用于全部数据，不只是当前页；排序后会跳回第一页。
  • 导出 JSON / TSV 始终包含全部行，与分页无关。

导出的细节

  • 勾选「首行是表头」时，复制 JSON 得到的是对象数组，键名取表头；表头为空或重名时会自动补成 列 N / 原名_2，避免互相覆盖。
  • TSV 导出时，含制表符、换行或双引号的单元格会用双引号包裹并转义，保证粘进表格软件不会错列。

来源与致谢

本工具的功能设计与交互移植自 jamalofski/praticulus 的 CSV Viewer（MIT 许可），在此做了中文化、界面统一，并修复了 BOM 未剥离与分隔符探测计入引号内字符两个缺陷，另加了编码探测与分页。
