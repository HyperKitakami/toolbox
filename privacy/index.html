隐私说明

这里没有需要你相信的承诺，只有可验证的事实。打开开发者工具的 Network 面板，你可以自己确认下面每一条。

不收集什么

  • 没有分析统计（Google Analytics、百度统计之类，一个都没有）。
  • 没有第三方追踪器、像素、广告脚本。
  • 没有 Cookie，没有账号，没有登录。
  • 除「AI 辅助」一组外，没有把你输入的内容发到任何服务器 —— 所有计算都在浏览器里完成。

网络请求

页面加载时只会请求本站自己的静态资源：HTML、CSS、JavaScript、图标和字体。 没有 CDN，没有外部字体服务，没有任何跨域请求。 「AI 辅助」以外的工具在运行期间也不会产生新的请求。

AI 辅助工具会联网

「AI 辅助」这一组工具需要用你自己申请的 API Key 调用外部大模型，运行时会向你选定的服务商 发起请求（Anthropic、OpenAI、Google，或你自己填写的接口地址）。你在页面上填的内容， 包括上传的音频和粘贴的文本，都会发过去，之后怎么处理以那家服务商的隐私政策为准。 本站不经手、也保存不了这些数据 —— 它没有服务器。

API Key 只存在你自己浏览器的 localStorage 里， 不会发往本站的任何地方。想彻底清掉，在工具页上点「清除 Key」， 或者清空该站点的浏览器数据。完全不用这一组工具的话，全站不会产生任何跨域请求。

本地存储

本站使用 localStorage 保存以下内容：

  • toolbox-theme —— 你选择的主题（深色或浅色）。 仅用于下次打开时保持一致，不含任何标识信息。
  • toolbox-whisper-verifier —— 「日语语音校对」自己保存的接口配置： 服务商、模型名、自定义接口地址，以及你填的 API Key。 Key 以明文存在本机、不会上传，但共用电脑上用完建议点「清除 Key」。

除此之外不写入任何数据。部分工具如果需要在刷新后保留草稿， 会在该工具的页面上单独说明，你可以随时在浏览器设置里清除。

第三方资源

本站不引入任何第三方库、字体或图标集。所有图标都是内联 SVG， 字体使用系统自带字体栈。因此不存在第三方服务能够观察到你访问过这里 —— 唯一的例外是上面说的 AI 辅助工具，而那次请求是你主动触发的。

托管

本站是静态站点，部署在静态托管服务上。托管方与普通 Web 服务器一样， 会在服务端日志中记录请求的 IP 与时间戳 —— 这是所有网站都无法避免的一层， 与本站的代码无关。如果你对这一点敏感，可以把仓库下载到本地， 用任意静态服务器打开：除「AI 辅助」之外的工具全部离线可用。

联系

发现与隐私相关的疏漏，欢迎直接开 issue。 对于隐私优先的站点来说，可审计比口头承诺重要得多。

工具箱
