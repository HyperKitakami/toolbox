关于本站

一个自己用的在线工具箱。想要什么工具就自己加一个， 不登录、不联网、不弹广告，随手打开就能用。

为什么做成静态的

大多数在线工具站都要把数据发到服务器上处理，哪怕只是格式化一段 JSON。 这个站不这么做：页面是静态文件，逻辑跑在浏览器里， 断网之后照样能用。你也可以右键「查看网页源代码」， 看到的就是实际运行的代码，没有任何打包和混淆。

技术形态

  • 纯静态：原生 HTML、CSS、JavaScript，没有框架，没有构建步骤。
  • 零第三方请求：不加载 CDN、字体、分析脚本。字体用系统字体栈。
  • 一个工具 = 一个目录 + 一个脚本：<slug>/index.html 加 js/tools/<slug>.js，逻辑不内联。
  • 数据驱动：首页、分类页、搜索全部由 js/registry.js 生成，加工具只改这一个文件。

目录结构

tools-box/
├── index.html                 首页：Hero + 分类 + 全部工具
├── 404.html
├── css/
│   ├── base.css               设计令牌、重置、通用组件（改配色只改这里）
│   ├── site.css               页头 / 页脚 / 首页 / 分类页 / 搜索面板
│   └── tool.css               工具页骨架（所有工具页复用）
├── js/
│   ├── theme-init.js          首屏前套用主题，避免深色模式闪白
│   ├── registry.js            ★ 唯一数据源：分类 + 工具清单
│   ├── site.js                主题、导航、卡片渲染、搜索
│   └── tools/
│       ├── _template.js       工具逻辑模板
│       └── word-counter.js
├── hubs/<id>/index.html       六个分类页（由脚本生成）
├── tools/
│   ├── _template/index.html   工具页模板：复制这个目录开新工具
│   └── word-counter/index.html
├── about/  privacy/
└── scripts/
    ├── chrome.mjs             页头页脚的唯一来源
    └── build-pages.mjs        生成分类页 + 同步页头页脚

怎么加一个新工具

三步，不用装任何依赖：

  1. 复制 tools/_template/ 为 tools/<slug>/， 改掉里面的标题、描述和 data-tool 属性。
  2. 把 js/tools/_template.js 复制为 js/tools/<slug>.js，在里面写逻辑。 页面底部按顺序引入它即可。
  3. 打开 js/registry.js， 在 TOOLS 数组里把对应那一行的状态 从 'planned' 改成 'ready'。 首页、分类页和搜索会自动收录。

如果改动了页头或页脚，跑一次 node scripts/build-pages.mjs， 它会把新的导航同步到所有页面，重新生成分类页，并刷新各页面里 CSS / JS 引用的版本号。

命名与代码约定

  • 工具目录名用短横线小写英文，例如 json-formatter。
  • 所有事件在 JavaScript 里绑定，不写内联 onclick。
  • 工具页复用 css/tool.css 的 .panel / .stat / .output 结构，保证全站观感一致。
  • 新增颜色一律用 css/base.css 里的 CSS 变量，不要写死色值。
